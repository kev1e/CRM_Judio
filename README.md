# Корпоративная CRM — комплект требований для Claude Code

**Версия спецификации:** v1.3 (утверждённые ответы 1–87, включая финальные решения 81–87).  
**Ревизия стека:** 2026-11-19 — backend переведён с NestJS/Prisma/BullMQ на Django + DRF / Django ORM / Celery, Telegram — aiogram (см. D025, D026, D029, D030 в `docs/DECISIONS.md`). Функциональные требования v1.3 не менялись.  
**Статус:** пакет проектирования и запуска разработки; **не реализованная CRM**.  
**Продукт:** универсальная CRM одной компании, до 20 сотрудников на старте, UX по мотивам YouGile, без копирования чужих исходных материалов/брендинга.

## Быстрый старт

1. Создайте пустой Git-репозиторий и скопируйте **всю папку** этого комплекта в корень.
2. Откройте репозиторий в Claude Code; начните с `prompts/00-bootstrap.md`.
3. Убедитесь, что Claude Code сначала прочитал `CLAUDE.md`, `docs/PRD.md`, `docs/PERMISSIONS.md`, `docs/OPEN_QUESTIONS.md` и другие документы, а **не начал генерировать всю CRM одним шагом**.
4. Фиксируйте решения на вопросы со статусом `BLOCKER` в `docs/OPEN_QUESTIONS.md`, а архитектурные решения — в `docs/DECISIONS.md`.
5. Начинайте разработку по `docs/ROADMAP.md`; каждый спринт завершайте проверкой критериев приёмки и тестов.

## Карта документов

- `CLAUDE.md` — обязательные инструкции агента.
- `docs/PRD.md` — продукт и бизнес-требования.
- `docs/PERMISSIONS.md` — модель доступа, сценарии и матрица разрешений.
- `docs/UX_GUIDELINES.md` — UX и UI.
- `docs/ARCHITECTURE.md` — технические модули и контракты.
- `docs/DATABASE.md` — концептуальная модель данных и миграции.
- `docs/TELEGRAM.md` — бот, Mini App, 2FA и уведомления.
- `docs/SECURITY.md` — защита информации, аудит и угрозы.
- `docs/ANALYTICS_AUTOMATIONS.md` — метрики, отчётность, автоматика.
- `docs/INFRASTRUCTURE.md` — VPS/Docker, CI/CD, мониторинг, резервирование.
- `docs/TEST_PLAN.md` — тесты, безопасность и приёмка.
- `docs/ROADMAP.md` — спринты, зависимые задачи и критерии готовности.
- `docs/DECISIONS.md` — журнал подтверждённых архитектурных решений.
- `docs/OPEN_QUESTIONS.md` — нерешённые вопросы и рабочие допущения.
- `prompts/00-bootstrap.md`, `prompts/01-sprint-prompt.md` — готовые промпты для Claude Code.

## Приоритет источников

1. Явно согласованные продуктовые решения в `docs/PRD.md` и `docs/DECISIONS.md`.
2. Подробные политики в `docs/PERMISSIONS.md`, `docs/SECURITY.md`, `docs/TELEGRAM.md`.
3. Архитектурные предложения в остальных документах, пока они не конфликтуют с требованиями.
4. Если имеются противоречия или пробелы, **не придумывать бизнес-политику**; зарегистрировать вопрос и запросить решение.

## Важно

- `v1.3` — название текущей консолидации после v1.2, а не новая самостоятельно утверждённая функциональность.
- Открытые решения **не считаются утверждёнными**: объём файлов, RPO/RTO, авторизация при потере Telegram, часть политик удаления/архивирования и т. д.
- Включённый технический стек — согласованный перечень технологий; точные версии и совместимость надо сверить перед установкой и зафиксировать в lockfile'ах (`pnpm-lock.yaml` для JS/TS, `uv.lock` для Python). Таблица проверенных версий — в `docs/ARCHITECTURE.md`.
